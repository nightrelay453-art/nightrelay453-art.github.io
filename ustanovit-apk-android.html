Как установить APK на Android

APK - это файл приложения. Его ставят, когда приложения нет в магазине. Так устанавливается и приложение NightRelay.

  1. Скачайте файл в браузере телефона.
  2. Откройте его из уведомления о загрузке или из папки «Загрузки».
  3. Телефон скажет, что установка из этого источника запрещена, и предложит открыть настройки. Включите «Разрешить установку» для браузера, через который скачивали.
  4. Вернитесь назад и нажмите «Установить».

Почему телефон предупреждает

Android так поступает с любым приложением не из магазина. Скачивайте APK только с сайта самого сервиса, а не со сборников файлов.

Обновления NightRelay приходят в самом приложении: скачивать файл заново не нужно.
